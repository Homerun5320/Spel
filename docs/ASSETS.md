# Assets

Policy: zero art assets. Terrain, ocean, atmosphere and stars are generated by shaders; models are procedural; flags are vector; audio is WebAudio; fonts are the system font stack.

Committed binaries today:
- `e2e/goldens/*.png`: golden screenshots, test fixtures only (exempt from "no binary game assets").
- `public/data/render.bin.gz` and `public/data/sim.bin.gz`: baked world packs (M01), about 4.5 MB together. They are DATA, not art: the elevation, land and country rasters baked by `tools/bake` from the two sources below. Together with the JSON files next to them they stay under 6 MB (`npm run bake:check` enforces it).

Downloaded data (M01), credited in `CREDITS.md` and checksummed in `public/data/checksums.json`:
- **Terrarium elevation tiles, zoom 4** (Mapzen terrain tiles from AWS: USGS SRTM, NOAA ETOPO1 and others). Attribution required; the exact Joerd source page could not be reached from the build sandbox, so `CREDITS.md` carries a general line (see Known issues in `docs/PROGRESS.md`).
- **Natural Earth** 50m admin 0 countries, 10m populated places simple, 10m ports, public domain, pinned to one commit SHA (recorded in `public/data/meta.json` and `CREDITS.md`).
- The terrain is stylised (smoothed z4 elevation, game classes), and says so.
