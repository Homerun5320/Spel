# Architecture detail: Host and mirror

Full module rows moved verbatim from `docs/ARCHITECTURE.md` (the index keeps one short row per module). Rows keep the old index order.

| Path | Purpose | Public API |
|------|---------|------------|
| `src/host/protocol.ts`, `src/host/accumulator.ts`, `src/host/mainThreadHost.ts` | The `SimHost` interface and every message that crosses it (plain data only), the fixed-timestep accumulator, the main-thread host. See "Sim flow" below. | `SimHost`, `HostEvent`, `StateDiff` (`fullOwner` when the outbox overflowed), `Snapshot` (`resume: HostResume`), `HostResume`, `Speed`, `ClientMessage`, `HostMessage`, `Port`, `cloneEvent`, `FixedStepAccumulator`, `TickDriver` (`onTick(view, submit)`, the option `driver` of `MainThreadHostOptions`), `MainThreadHost` (`submitIntent`, `setSpeed`, `advance`, `subscribe`, `requestSnapshot`, `dispose`, `tick`, `speed`, `droppedIntents`, static `resume(snapshot)`) |
| `src/host/viewMirror.ts` | `ViewMirror`: the page's read-only COPY of the match, implements `SimView`. Built from one `requestView()` answer (full owner array, terrain layer, statistics) and kept current by the host's `diff` events (changed cells written in place, `fullOwner` adopted after an outbox overflow, `diff.view` for the statistics); diffs that arrive before the first answer are queued. `onFrame(listener)` tells the consumers (the ownership texture) what changed. Nothing in it refers to the sim. | `ViewMirror` (`attach(host)`, `onFrame`, `apply`, `copyOwner`, `packedStats`, `speed`, `lastRejectReason`, `lastRejectTick`, `frames`), `FrameListener` |
| `src/host/viewEventRing.ts`, `src/host/viewEventFilter.ts` (Events-1) | The page's side-fact channel. `ViewEventRing`: a fixed `Int32Array` ring of `VIEW_EVENTS_CAP` (128, `src/sim/view.ts`) events, 4 integers each (kind, tick, a, b), newest kept, oldest counted in `dropped`; allocated once, no object per event. `MainThreadHost` pushes every outbox event except `OUTBOX_PAINT` and `OUTBOX_REJECT` that `ViewEventFilter.accept` lets through (unknown kinds pass as they are), and every diff's `ViewSnapshot.events` (packed, oldest first) and `eventsDropped` EMPTY the ring (a diff for many ticks holds them all; the full view `requestView` does not drain). Filter: an event about a helicopter (`a` = id) of a seat at war with the viewer is sent only when `heliVisibilityOf(state).sight(viewerSeat)` holds that helicopter after the step; a slot freed in the step is judged by its owner before it; own and non-hostile always; no viewer seat = everything. `ViewMirror.events` (`ViewEventsView` of `src/sim/view.ts`: `length`, `dropped`, `kindAt`, `tickAt`, `aAt`, `bAt`) collects the frames' facts until the single consumer calls `clearEvents()`; a `StateView` answers `EMPTY_VIEW_EVENTS`. | `ViewEventRing`, `ViewEventFilter`, `isHeliEvent` |
| `src/host/structureSnapshot.ts`, `src/host/structureMirror.ts` (M10a) | The structure table on its way to the page. `snapshotStructures(table)` copies the sim's table into a `StructureSnapshot` (typed arrays for slots 0..highWater-1: type, owner, cell, level, buildTick, readyTick, upgradeReadyTick; `deleteReady` per owner; `counts` per (owner, type); never a sim reference), `structureSignature(table)` is the 32-bit fingerprint the host uses to put the table in a frame's diff only when it changed (`ViewSnapshot.structures`, null otherwise; always present in `requestView`). `MirrorStructures implements StructureView` is the page's copy (replaced whole by `adopt`, a cell index rebuilt then, `version` moves), so `validateBuild`, `buildPriceMilli` and every reader work on a `ViewMirror` (`mirror.structures`, `mirror.structuresVersion`). `structureProgress(view, id, tick)` = the build progress 0..1 from `buildTick` / `readyTick` (the table has no stored progress). | `StructureSnapshot`, `MirrorStructures`, `structureProgress` |
| `src/host/aiDriver.ts` | `AiDriver implements TickDriver`: one `AiMemory` per non-human seat, ONE random stream PER SEAT (`createRng(aiSeatSeed(seed, seat))`, D118; never the sim's), calls `think` for every AI seat at every tick boundary and submits what it answers through the host (filed for T + 2). `new AiDriver(seed, { humanSeats })`: the human seats are a parameter (default `[0]`), the first is the anchor of the AI's capital places. It also keeps the cells of the Spawns it has sent that are not yet visible in the view (tick T to T + 2) and passes them to `think` as `inFlight`, so seats can Spawn on consecutive ticks without meeting (D109). Counter `sent`. See "The AI call" below. | `AiDriver` (`onTick`, `memoryOf`, `plays`, `streamOf`, `sent`), `aiSeatSeed`, `AiDriverOptions` |
| `src/host/transport.ts`, `src/host/remote.ts` | `LocalTransport` (a pair of ports that copy with `structuredClone`) and the two halves of a SimHost over a port: `serveHost` next to the host, `RemoteHost` next to the UI. The Worker of M24a replaces the local pair by a Worker's port. | `createLocalTransport()` (`client`, `host`, `idle()`, `copies`), `serveHost(host, port)`, `RemoteHost` |
| `src/host/frontSnapshot.ts`, `src/host/frontMirror.ts` (M20a-2) | The attack fronts on their way to the page: `snapshotFronts(state)` copies `fillAttackFronts` (src/sim/view.ts: the frontier bags sampled, at most 96 entries looked at and 24 used per attack, 16 attacks) into typed arrays; `frontSignature(state)` is the attack list plus the tick over `FRONT_REFRESH_TICKS` (10) while an attack runs, so `ViewSnapshot.fronts` is in a diff once a second during an attack and never otherwise. `MirrorFronts` (fixed arrays, no allocation) is `ViewMirror.fronts`, `frontsVersion` moves on a new table. | `snapshotFronts`, `frontSignature`, `FRONT_REFRESH_TICKS`, `NO_FRONTS`, `MirrorFronts`, `AttackFrontSnapshot` |
| `viewerSeat` of `MainThreadHostOptions`, `snapshotHelis(t, slots, sight?)`, `heliSignature(t, sight?)` (M17-pre) | `new MainThreadHost(state, { viewerSeat })` (set by `MatchSession.fromMatch` to the human seat): the helicopter table of every snapshot and diff holds only the rows `heliVisibilityOf(state).sight(viewerSeat)` lists; a hidden row is sent as a free slot (all zero, not counted in `counts` or `liveCount`), ids stay in place. The signature folds only visible rows, so a relation or sensor change with a standing helicopter still produces a diff. Without `viewerSeat` (tests, debug pages) the whole table is sent. The layer, the effects, the list and `MissionWatcher` already treat owner 0 as gone; the own rows are always visible, so a shot-down own helicopter stays 50 ticks as before. | `viewerSeat`, `snapshotHelis`, `ViewMirror.visibleHelis` | [host](arch/host.md) |

Fix-6B additions: `src/host/viewEventRing.ts` `EventReader` (one cursor per consumer over the mirror's events, `ViewMirror.eventReader()`; `read()` the unread window, `commit()` at the end of the frame; `ViewEventRing.pushed` is the monotone sequence number); `MainThreadHost.viewer` (read-only: the seat the host filters for); `MatchSession.create` now filters for seat 0 like `fromMatch`; `MatchSession.shipEvents` is the ship news' reader.
