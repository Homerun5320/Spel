# Architecture detail: Tools and scripts

Full module rows moved verbatim from `docs/ARCHITECTURE.md` (the index keeps one short row per module). Rows keep the old index order.

| Path | Purpose | Public API |
|------|---------|------------|
| `scripts/artifact-pack.mjs` and `scripts/artifact-pack.d.mts` | `npm run artifact:pack`: dist to the artifact folder (fragment, whitelist, containers, batches, probe, link check). Procedure: `docs/PREVIEW.md`. | `pack(argv, opts)`, `toFragment`, `checkLinks`, `makeBatches`, `makeProbePack`, `ALLOWED_EXT`, CLI flags `--container --prev --probe --dist --out` |
| `tools/gen/lut.ts`, `tools/sim/run.ts` | Table generator; the CLI `npm run sim:run -- --seed N --ticks T [--canary --json --width --height --seats --no-debug-intents]`. | `buildLutSource`, `parseArgs`, `run`, `format` |
| `tools/sim/realWorld.ts`, `tools/sim/scenario.ts`, `tools/sim/bots.ts`, `tools/sim/bands.ts` | The headless scenario runner on the real world (`npm run sim:scenario -- --seed N --minutes 10 --players 12 --tribes 20 [--solo --country RUS --no-fighters --json]`): seats on the capitals of the largest countries (order by seed hash), scripted bots (`botIntents`: expander, fighter) that live in tools and never in `src/sim`, territory per minute, the calibration bands `SOLO_BAND` of the solo expander (D88). | `loadRealWorld`, `parseArgs`, `runScenario`, `format`, `largestCountries`, `pickCountries`, `botIntents`, `SOLO_BAND` |
| `tools/sim/pace.ts`, `tools/sim/paceMath.ts`, `tools/sim/humanBot.ts` | The PACE REPORT of the tempo pass (D142): `npm run sim:pace [-- --part solo,conquest,match --seeds 1,2,3,4,5 --minutes 25 --setup play,skirmish,asia --json]`, deterministic and headless, game seconds at 1x. Part solo: the free-expansion curve at minutes 1, 2, 3, 5, 10 on six capitals, plus the gold income per second and the earliest minute an expander that buys nothing could pay each price of `--prices` (default 1 000, 2 400, 7 000, 20 000: later milestones price things in gold and land now arrives sooner, D143). Part conquest: two seats on a real border at troop PARITY (`runConquest`: whole 197-cell disc, or 500 cells of a country the defender grew first; 100 % and 40 % commitment, repeated clicks or one, passive or counter-attacking defender; five locations). Part match: the default Play match (you + 5 AI + 20 tribes) and a 12-AI Skirmish (Europe) through `createMatch`, the real `AiDriver` and the scripted sane human (`HumanBot`: expands, keeps 40 % of its cap in reserve, attacks the weakest neighbour it outnumbers 1.5 to 1 at 60 %), plus a passive human for 5 minutes (a third setup `asia` = you + 5 AI + 20 tribes in East Asia is run on request); the guard rails of `tools/sim/paceMath.ts` (top AI share at minute 10 <= 25 % and at minutes 15, 20, 25 <= 25 %, nations and tribes alive at minute 3 >= 75 %, no frozen board before minute 21, a passive player alive at 5 minutes: D143) are printed as PASS / FAIL. Re-run it after ANY change of a constant in `src/sim/rules.ts`. | `parseArgs`, `minuteReaching`, `runSolo`, `runConquest`, `runConquestTable`, `runMatch`, `runPace`, `median`, `secondsToReach`, `evaluateMatchGuards`, `evaluatePassiveGuard`, `frozenAtMinute`, `passiveAlive`, `HumanBot`, `CompositeDriver` |
| `debug/sim.html`, `src/app/debugSim.ts` | The simulation hash page: runs the golden scenario (step loop and MainThreadHost) and the canary; `?seed=` / `?ticks=` or `#seed-2_ticks-1000`. | `window.__debugSim` |
| `scripts/shot.mjs` and `scripts/shot.d.mts` | Playwright launcher and test harness; CLI = `npm run shots`. | `launchBrowser`, `openPage` (a tab of a shared context per viewport; `{ isolated: true }` for heap and leak tests), `newTestPage`, `waitFrames(page, n)` (a frame count instead of a sleep), `takeShot`, `renderAndCapture`, `analyzeImage`, `checkImageStats`, `checkShot`, `assertShotOk`, `compareGolden`, `heapDelta`, `readUsedHeap`, `startViteServer`, `guard`, `CHROMIUM_ARGS`, `THRESHOLDS`, `ALLOWED_CONSOLE_WARNINGS` |
| `scripts/localGpu.mjs` and `scripts/localGpu.d.mts` | LOCAL GPU MODE (D144, `docs/LOCAL.md`): pure helpers for `LOCAL_GPU=1`: the Chromium switches without SwiftShader, the browser path (`CHROMIUM_PATH`, `CHROME_PATH`, an installed Chrome / Edge, Playwright's own), the e2e worker count (`E2E_WORKERS`, else cores - 1 up to 3 in `vitest.config.ts`, with the switch floor(cores / 2) up to 4), golden comparison warn-only. Without the switch every helper returns exactly what the cloud always used (`tests/localGpu.test.ts` pins the argument array). | `SWIFTSHADER_ARGS`, `LOCAL_GPU_ARGS`, `isLocalGpu`, `chromiumArgs`, `resolveLocalBrowserPath`, `candidateBrowserPaths`, `e2eWorkerCount`, `localWorkerCount`, `goldenCompareMode`, `isDriverPerformanceHint`, `downgradeDriverHints` (real-GPU driver performance hints are not console warnings) |
| `scripts/verify.mjs` and `scripts/verify.d.mts` | `npm run verify`, `verify:fast`, `verify:local` as one cross-platform Node script: typecheck, lint and unit side by side, then perf alone, then the e2e project (a few Chromium instances), then the e2e-serial project (heap, leak and wall-clock tests, one file at a time); a timing table at the end; `--local` sets `LOCAL_GPU=1`, runs a GPU check first, continues after a failure and writes `test-results/local-report.txt`. | `stageGroups`, `formatSummary`, `formatDuration`, `main` |
| `scripts/test-inventory.mjs` and `scripts/test-inventory.d.mts` | The TestSpeed inventory: every test name and `expect(` count per file of a run (vitest JSON reports) and a comparison that fails when a case or an assertion count was lost (a moved case is reported, not lost). | `inventoryFromReports`, `compareInventories`, `countExpects` |
