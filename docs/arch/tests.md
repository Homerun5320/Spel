## Test hooks (`?test=1`)

`window.__test` (defined in `src/app/main.ts`):
- `render()`: render one frame synchronously with the fixed test-view sun.
- `info()`: GL renderer string, WebGL2 flag, draw calls, triangles, textures, geometries, size, DPR, `firstFrameMs`, `frames`, `testMode`.

Since M02 the default scene is the stylised Earth (`?scene=spike` is the M00 spike, which only has `render` and `info`). `window.__test` of the globe scene (`src/app/globeApp.ts`):
- `render(dt = 0)`: steps the fx clock by `dt`, then renders one frame (camera inertia, wheel zoom and the sun follow the fx clock).
- `settle(dt, n)` (D144): `n` frames of `dt` seconds of which only the last is drawn; it leaves exactly the state `n` calls of `render(dt)` leave (fx clock, flights, camera inertia, chunk LOD hysteresis, HUD, the `frames` counter) at the cost of one GL draw (`Globe.render(false)` skips only `renderer.render`). A SwiftShader frame costs about 0.55 s at 960x540, so waits in which nobody looks at the pictures use it.
- `info()`: GL renderer string, WebGL2 flag, draw calls, triangles, textures, geometries, texture MB, size, DPR, tier and mesh size, `firstFrameMs`, `frames`, `fx`.
- `setView({lat, lon, distKm, heading, tilt, time})`: camera (limits applied) and, when `time` is given, the fx clock in seconds; does not render. `view()` returns the clamped camera. M07a: `setView({..., altAglM})` puts the camera that many metres above the displaced ground under it (the focus lat / lon, heading and tilt stay as given; the distance is solved, see `setViewAtAgl`), BYPASSES the user's zoom limit and the tilt clamp (tilt up to 89.5), and the near / far planes follow the height (they always do in chunk mode); every `setView` also forgets the chunk LOD hysteresis, so a view never depends on the path that led to it.
- `project(lat, lon)`: canvas pixel of the displaced surface point (`x`, `y`, `inView`, `facing`).
- `pick(x, y)`: surface pick (lat, lon, sim cell, class, country, elevation) or null; `tooltip(x, y)`: the tooltip text for that pixel.
- `advance(dt, ticks = 0)`: steps the fx clock by `dt` seconds, then runs exactly `ticks` sim ticks whatever the speed (and flushes the ownership texture, so the next render shows them). M05 added the sim part.
- `readTexels(name, points)`: texels of `height`, `bathy`, `country` or `terrainClass` as the GPU holds them.
- `setExaggeration(x)`: height exaggeration of shader and picking (0 = flat control).
- `setBorderStrength(x)`: strength of the country border lines (0 = none, default 0.34).
- M05, the match: in test mode the match exists from the first line (no start screen; seed from `?seed=` / `#seed-N`, default 1; `debugIntents` on; HUD hidden unless `#hud` / `?hud=1`; HUD numbers not interpolated, so they equal the sim values). `state()`: `{tick, phase, speed, paused, seed, rejects, lastRejectReason, commitPct, local: {spawned, cells, troops, troopsQt, capQt, gold, goldMilli, goldPerSecMilli, landShareQ15, landSharePct, alive}, seats: [...], ownership: {uploads, gpuUploads, dirty}, hostAdvance: {frames, meanMs, p95Ms, maxMs}}`. `submit(body)`: a raw intent of any seat through the host (effective T + 2 ticks later; how the negative tests send illegal ones). `give(seat, {gold, troops})`: a `DebugGive` intent (never a direct write). `hash()`: the sim state hash (a snapshot request). `text(key, params?)`: `t()` in the page, throws on a missing key in test mode (the e2e proof of the strict rule); `language()`: `'sv'` or `'en'`; `hudRefresh(n)`: runs the HUD refresh n times on an unchanged state and returns the milliseconds (the test that it does no DOM work). `run(seconds, fps = 60)`: frames of 1/fps of wall time without drawing (fx clock, `host.advance`, throttled ownership flush), returns `{uploads, ticks}`. `readOwnership(cells)`: the owners the GPU texture holds; `ownerOf(cell)`: the mirror's owner; `setSpeed(0|1|2|4)`.
- M06 (menus): `?test=1&menu=1` (`#test_menu`) shows the start screen instead of starting the standard match; the setup then runs through the DOM (`data-testid`s above). Hooks: `setupCountries(region?)` (every country with its eligibility, the key of its reason and its land mass), `buildHash(config, ticks)` (the page's own `createMatch`, the hashes at tick 0 and after `ticks` ticks with the AI, nothing is started), `seatCells()` (cells and capital cell per seat), `ownedOutside(region)` (owned cells outside a region's mask, must be 0), `view()` (camera) and `render(dt)` (steps a flight). `state().seed` is the config's seed for a built match.
- Mouse works in test mode too (real `page.mouse` events); left drag = grab, right drag (or ctrl / shift) = heading and tilt, wheel = zoom at the cursor.
- M07a (terrain): `state().terrainMode` is `'chunks'` (the default) or `'fixed'` (`?terrain=fixed`, `#terrain-fixed`); `state().terrain` and `terrain()` (also available without a match) are `{chunkCount, lodLevels (distinct quadtree levels among the chunks drawn), triangles (chunks times the triangles of one instance, skirts included), drawCalls (1 for the instanced terrain), levels, capped (true = the tier's chunk cap refused splits the camera distance asked for), finite (every float of the instance data is finite)}` of the LAST rendered frame; `info().triangles` is the whole scene (terrain + the 9024 triangles of the atmosphere shell) and `info().terrainMode` the mode. `terrainLeaves()`: the chunks of the last frame as `{level, ix, iy, coarser}` (levels the neighbour across the west, east, north, south edge is coarser). `setSkirts(on)` (the crack test proves its detector with it), `setChunkDebug(on)` (`?chunks=1`), `setClearColor(0xRRGGBB)` (the crack test clears to magenta `0xff00ff`), `cameraAglM()`. `render()` waits for the GL queue (`Globe.finish`) because no frame is presented between the calls of a test. URL params: `terrain=fixed`, `chunks=1`, and `chunktier=low|medium|high` (test mode only: the chunk density, split distances and chunk cap of that tier on the deterministic test settings, how the headless high-tier run is made).
- M07a part B: `setGroundView({lat, lon, heading, pitchDeg, aglM, time?})`: the camera given by its own position (`aglM` metres above the displaced ground under it), compass `heading` and `pitchDeg` below the horizon, without the user's zoom and tilt limits (a ray above the sea-level horizon is aimed at it); `time` sets the fx clock (the sun); does not render; forgets the LOD hysteresis. `?view=alps-valley` and `?view=himalaya-valley` (hash `#view-alps-valley`, `#view-himalaya-valley`) start the page in the named ground view (`src/render/views.ts` `GROUND_VIEWS`) and keep the globe from spinning behind the start screen; in the fixed mode they are ignored. In chunk mode the wheel (and `setView`) stop the camera 1000 m above the displaced ground under it; `cameraAglM()` reads that height.

- M07b part A (the terrain detail; debug hooks, the probe): `probeEncoding()` is `'float'` (an RGBA32F render target, `EXT_color_buffer_float`) or `'bytes'` (packed RGBA8); every probe takes an optional encoding to force one (both give identical values). `probeHash(items, encoding?)` returns the integer hash of each `[ix, iy, iz, seed]` (lattice coordinates already shifted by 2^20, the seed a uint32) computed by the GLSL function `detHash3`; `probeNoise(items, ridge?)` the value noise (or its ridge) of each `[x, y, z, seed]`; `probeHeight(points, encoding?)` the height in render metres (before the exaggeration) of each `[latitude, longitude, octaves]` computed by the GLSL `detHeight` from the raster the page uploaded (the point's unit direction is made on the CPU in double precision, see `src/render/detailProbe.ts`; latitude and longitude are float32 on the GPU, so a test evaluates TypeScript at the same `Math.fround` values); `probeVertex(points, encoding?)` the height the vertex shader draws at each `[latitude, longitude, chunk level, camera x, y, z (Earth radii)]` (`detVertexHeight`: octaves = the smaller of the level's and the distance law's); `detailLod()` is `[offset of the distance law, level bias, 1 = detail on]` (null in the fixed mode); `heightAt(lat, lon, octaves?)` is the module `heightAt` bound to the page's raster; `pickSurface(x, y)` is `{lat, lon, radius}` of the surface point the picking finds under a pixel (the displaced surface including the detail) and `cameraPosition()` the camera in Earth radii. `?detail=0` (hash `#detail-0`, Dev panel "Terrängdetalj av") switches the detail off: the coast rule stays (sea exactly 0, land at least 1 m) but there are no octaves and the facet normal fades below four texels per cell as in M07a. M07b audit (D154): `probeRelief(points, encoding?)` is the GLSL local relief in metres of each `[latitude, longitude]` (-1 on sea; the 3x3 rule, the 100 m floor and the polar fade of `detSample`); `setDetailBias(octaves)` (0 to -3: moves the distance law of the vertex octaves, GPU uniform and picking together) and `detailBias()`; `setFineDetail(on)` and `fineDetail()` (the near-view mottling, `uMottleScale`, `?mottle=0` / `#mottle-0`); `setChunkDensity(scale)` (0.5 to 2, every split distance of the quadtree times it) and `chunkDensity()`; `setOctaveLimit('law' | 'level' | 'none')` (the pop controls: the real law, octaves by the level alone, every limit off). These are the run-time levers of the terrain's cost for M24a (they are `Globe` methods of the same names).

- CamFix (D158): `shownTilt()` (the tilt the camera shows: the user's tilt eased down at the far distances; `view().tilt` is the user's) and `maxDist()` (the farthest distance of this window, km); the zoom-out pictures take `?test=1&w=<px>&h=<px>` to give the canvas the shape of the window (the viewport alone does not resize the canvas in test mode).
- M08 part A (RTS camera): `flyTo(lat, lon, distKm, options?)` (with `options.altAglM` the RTS flight: arrive that many metres over the ground point, `tilt`, `heading`, `durationS`; 0 jumps), `bookmark(name, durationS?)` for 'alps', 'himalaya', 'andes', 'capital' (false when the capital is not spawned), `flightActive()`, `cameraMix()` (the RTS weight, 0 to 1), `holdAgl()` (the height the camera keeps, null = none), `pickGround(x, y)` (`{lat, lon, radius, seenHeightM}` of the ground under a pixel, the surface the camera sees), `groundHeightAt(lat, lon, octaves?)` (the module `heightAt`, render metres). The wheel, the drag, the right drag, F and Escape work with real mouse and key events in test mode; `setView` and the other hooks never set a kept height, so a hook-made view does not move by itself.

`window.__debugSim` (debug/sim.html, M03): `ready`, `seed`, `ticks`, `engineVersion`, `formatVersion`, `mapHash`, `hashes` (per golden tick, hex), `hostHashes` (the same run through MainThreadHost), `adversarialHashes` (raw turn lists), `canary` (`values`, `hash`). The page sets `body[data-ready="1"]`.

`window.__debugData` (debug/data.html, no test mode needed): `mode`, `loadMs`, `timings`, `measureLoad(n)` (n full loads, ms each), `setMode(mode)`. The page sets `body[data-ready="1"]`, `body[data-checksums="ok"]`, `body[data-map]`, `body[data-load-ms]`.

- M10a (structures): `props()` = `{counts (instances in the draw per type number), total, dropped, cityTriangles, list (id, type, owner, cell, level, lat, lon, radius, heightM of every drawn instance, float64), placing (type being placed, 0 = none), ghost ({type, cell, ok, reason} or null), toasts (text keys on screen), buildBar ({visible, cityPrice})}`; `state().structures = {count, byType}` (the snapshot's table, every owner). With `?hud=1` the build bar is shown in test mode; key 1 and `[data-testid="build-city"]` start the placement.

Test-mode URL params (the same keys work as a hash, `#test_perf`): `test=1`, `perf=1` (overlay), `devbtn=1` (show the Dev button in test mode, it is hidden there so screenshots stay clean), `hud=1` (show the match HUD in test mode), `menu=1` (M06: the menus instead of the standard match at once), `blank=1` (debug: empty canvas), `lang=en` (English UI; `#test_lang-en`), `seed=N` (the match seed; `#test_seed-7` is the same match as `?test=1&seed=7`), `ai=0` (no AI nations and no tribes: the 25 other seats stay empty; the e2e files of parts A and B open with it, `#test_ai-0_seed-7`; the default is the AI on, also in test mode, where it needs ticks to run: the tribes and nations appear when `advance` runs the sim), `w=`, `h=` (default 960x540). Later milestones list their hooks here. AutoTier-2 (D160): `adapt=0` / `adapt=1` (the adaptive resolution; `__test.adaptive` = `enable(on)`, `feed(ms, n)`, `simulate(a, b, frames)` (frame time a + b * scale^2), `info()`).
