Bildgenerator

Skriv en mening, få en bild. Eller ge den en bild och be den ändra den.

>

Scrolla ner. Bilden bakom texten skärps.

Från brus till bild

  1. Slumpbrus. Modellen startar från ren slump. Samma seed ger samma brus och därför samma bild.
  2. Avbrusning. I runt 30 små steg tar den bort lite brus i taget, styrd av din prompt.
  3. Bild. När bruset är borta är bilden klar.

Bakgrunden gör samma sak medan du scrollar. Tryck för att slumpa fram en ny.

Kom igång

Programmet körs på din egen dator. Du behöver Python 3.10 eller nyare.

git clone https://github.com/Homerun5320/Spel.git
cd Spel
pip install -r requirements.txt
python app.py

Öppna sedan http://127.0.0.1:7860, skriv en prompt och tryck på Generera. Vill du slippa webbläsaren går det från kommandoraden:

python -m bildgenerator "a red dragon over a snowy mountain"

Första starten laddar ner modellen, cirka 4 GB. Med ett NVIDIA-kort tar en bild några sekunder, på CPU flera minuter.

Bild till bild

Ge en startbild och beskriv hur den ska ändras. Förändring bestämmer hur långt tillbaka i brus bilden skickas innan den byggs upp igen.

startbildresultat

python -m bildgenerator "the same scene at sunset, oil painting" --bild foto.jpg --förändring 0.6

Illustrationen visar principen, den är inte utdata från modellen.

Gott att veta

  • Den här sidan beskriver bara verktyget. Bilderna skapas på din dator, inte i webbläsaren.
  • Engelska prompts ger oftast bäst resultat.
  • Samma seed och samma inställningar ger samma bild.
  • Bygger på Stable Diffusion 1.5 via biblioteket diffusers. Byt modell med --modell.
