# Credits

## Data

The world in this game is baked offline from two public sources and committed as small binary packs in `public/data/` (the tool is `tools/bake`, checksums are in `public/data/checksums.json`).

- **Terrain elevation: Terrarium tiles (zoom 4), "Mapzen terrain tiles".** Hosted on AWS Open Data (`elevation-tiles-prod.s3.amazonaws.com`). The tiles combine several public elevation sources, among them USGS SRTM, NOAA ETOPO1 (bathymetry) and others. Attribution required. The full source list of the tile set is kept on the Mapzen/Joerd attribution page, which could not be reached from the build environment, so this is a general credit line; see "Known issues" in `docs/PROGRESS.md`.
- **Country borders, populated places and ports: Natural Earth** (50m admin 0 countries, 10m populated places simple, 10m ports), public domain, from <https://github.com/nvkelso/natural-earth-vector> at commit `ca96624a56bd078437bca8184e78163e5039ad19`. Natural Earth asks for no credit; it is named here anyway.

The terrain is **stylised**: Terrarium z4 elevation (about 10 km per pixel) is smoothed, clamped, median-filtered and re-classified into game terrain classes. It is not survey data and must not be used as such. Borders follow the Natural Earth de facto lines.

## Code and assets

No code, names, maps, branding or assets are taken from any other game. There are no art assets; everything visible is generated by code (see `docs/ASSETS.md`).
