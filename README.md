# Spel

**Svenska.** Ett originellt 3D-krigsspel i webbläsaren på ett stiliserat klot (clean-room: genren är inspirerad av territoriespel, men ingen kod, inga namn, kartor eller assets är kopierade). Just nu finns bara grundverktygen: `npm ci`, sedan `npm run verify:fast` (snabb kontroll) och `npm run verify` (allt, inklusive en headless WebGL2-skärmdump). Regler för arbetet finns i `CLAUDE.md` och `docs/CHARTER.md`. Utveckling: `npm run dev`.

**English.** An original 3D browser war-strategy game on a stylised globe (clean room: genre inspiration only, no code, names, maps or assets copied). Only the harness exists so far: `npm ci`, then `npm run verify:fast` (quick check) and `npm run verify` (everything, including a headless WebGL2 screenshot). Working rules are in `CLAUDE.md` and `docs/CHARTER.md`. Development: `npm run dev`.
