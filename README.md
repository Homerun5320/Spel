# Spel

**Svenska.** Ett originellt 3D-krigsspel i webbläsaren på ett stiliserat klot (clean-room: genren är inspirerad av territoriespel, men ingen kod, inga namn, kartor eller assets är kopierade). Just nu finns grundverktygen och den bakade världsdatan (terräng, länder, städer, hamnar; se `CREDITS.md`) med en debugkarta (`debug/data.html`): `npm ci`, sedan `npm run verify:fast` (snabb kontroll) och `npm run verify` (allt, inklusive en headless WebGL2-skärmdump). Regler för arbetet finns i `CLAUDE.md` och `docs/CHARTER.md`. Utveckling: `npm run dev`. På en egen dator med grafikkort (Windows): `docs/LOCAL.md` och `npm run verify:local`.

**English.** An original 3D browser war-strategy game on a stylised globe (clean room: genre inspiration only, no code, names, maps or assets copied). The harness and the baked world data (terrain, countries, cities, ports; see `CREDITS.md`) with a debug map (`debug/data.html`) exist so far: `npm ci`, then `npm run verify:fast` (quick check) and `npm run verify` (everything, including a headless WebGL2 screenshot). Working rules are in `CLAUDE.md` and `docs/CHARTER.md`. Development: `npm run dev`. On your own PC with a GPU (Windows): `docs/LOCAL.md` (Swedish) and `npm run verify:local`.
